ИНСТРУКЦИЯ ПО ЗАПУСКУ И ОПИСАНИЕ РЕШЕНИЯ
Тестовое задание: Сбор и анализ арбитражных дел группы Сбер

1. Системные требования
   - Установленный интерпретатор Python версии 3.8 или выше.

2. Установка необходимых библиотек (Pandas, OpenPyXL):
   Выполните в командной строке:
   pip install pandas openpyxl

3. Примечание о версиях проекта и технические ограничения:
   В проекте реализованы две версии решения:

   - Версия 1 () (попытка прямого автоматического парсинга):
     В коде реализован механизм отправки прямых HTTP-запросов к официальной
     картотеке арбитражных дел (kad.arbitr.ru) и открытым агрегаторам (checko.ru).
     * Проблема: Данная версия не может собрать данные в автоматическом режиме,
       так как государственные и коммерческие реестры защищены антибот-системами
       (Cloudflare, DDoS-GUARD, WAF, капча) и возвращают ошибки 403 Forbidden /
       страницу проверки человека. Прямой скриптовый скрапинг этих ресурсов
       без платных официальных API-ключей или сервисов решения капчи невозможен.

   - Версия 2 (финальная аналитическая версия — version2.py):
     Обрабатывает выгруженный массив данных по судам Екатеринбурга, решая
     основные аналитические задачи задания: нормализацию данных, классификацию
     по инстанциям, расчет сводных витрин и генерацию отчета.

4. Инструкция по запуску рабочей версии:
   python version2.py
   (или: python3 version2.py)

5. Результат работы скрипта:
   Скрипт создает в текущей папке файл отчета:
   "sber_ekb_report.xlsx"

   Структура созданного Excel-файла:
   - Лист 1: "1. Реестр дел Екатеринбург" (детальные данные по каждому делу).
   - Лист 2: "2. По компаниям" (число дел, уникальные споры, суммы, доли).
   - Лист 3: "3. По судам Екатеринбурга" (распределение нагрузки по инстанциям).

   Во всех таблицах Excel настроен числовой формат с разделением разрядов (#,##0.00),
   автоподбор ширины столбцов и границы ячеек.
